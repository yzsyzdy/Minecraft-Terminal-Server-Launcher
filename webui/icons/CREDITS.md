## 为什么还有 `*-mask.png`

原图是**纯黑白**的应用图标（浅色底板 + 深色图形）。面板有深浅两套主题，如果直接贴原图，
深色主题下会得到一张刺眼的浅色方块。所以构建时把它们转成**单色蒙版**：按亮度取 alpha、
裁掉圆角底板、统一成 56×56 居中；界面里用 CSS `mask` + `currentColor` 着色——
亮色主题显示为黑，暗色主题自动变成白，也就是「颜色反转」，不需要维护两套图。

蒙版是原图的程序化衍生，不引入新的版权内容；原图保留在同目录，便于追溯与替换。
