# Features

MSTL's three feature modules. What they share is that all of them fetch data over the network, so all of them rely on the unified `http_utils` request layer.

- [Plugin management](plugin-management.md): search and install from SpigotMC / Modrinth / Hangar
- [Mod management](mod-management.md): Modrinth and CurseForge, filtered by version and loader
- [Tunneling](tunnel.md): local frpc and OpenFrp cloud tunnels
- [Web panel](web-panel.md): start and stop instances from a browser, watch the console, send commands
