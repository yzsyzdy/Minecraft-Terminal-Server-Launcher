    AI 助手¶

    网页面板里的第三个标签页。用自然语言让模型替你看状态、查日志、翻文件、改配置，也能启停实例和往控制台发指令 —— 但凡是会改动东西的操作，都要你在面板上点一下确认。

    它做什么¶

    你说 它调用的工具 谁执行
    「服务器现在什么状态？」 list_instances、get_instance 自动
    「最近日志有什么报错？」 read_console 自动
    「plugins 目录里有什么？」 list_files 自动
    「把 server.properties 读给我看」 read_file 自动
    「帮我把 survival 启动起来」 start_instance 你确认后
    「停掉 creative」 stop_instance 你确认后
    「重启 survival」 restart_instance 你确认后
    「在控制台说一句服务器今晚开」 send_command 你确认后
    「内存改成 6G，打开自动重启」 update_config 你确认后
    「把 motd 改成『欢迎』」 write_file 你确认后

    只读的五个工具直接跑，结果回到模型手里继续推理；要动东西的六个工具不会执行，而是先变成一张待确认卡片，你在面板上点「执行」才真正落地。

    配置¶

    打开面板的 设置 → AI 助手：

    字段 说明
    启用 AI 助手 总开关，关着的时候标签页只显示一句提示
    接口地址 OpenAI 兼容的 /v1 地址，例如 https://api.openai.com/v1
    模型名 服务商那边的模型标识，例如 gpt-4o-mini
    API Key 只写不读 —— 面板永远不回显已保存的 key，输入框留空表示不修改

    也可以直接写 config.json：

    {
  "ai": {
    "enabled": true,
    "base_url": "https://api.openai.com/v1",
    "model": "gpt-4o-mini",
    "api_key": "sk-..."
  }
}

    用环境变量放 key

    设置 MSTL_AI_API_KEY 后它会优先于 config.json 里的值，面板会显示「已由环境变量提供」并锁住输入框。适合把 key 放在启动脚本里而不是落在磁盘上。

    任何 OpenAI 兼容的服务都能用：官方接口、Azure OpenAI 的兼容层、自建的 vLLM / Ollama / one-api 网关。走的是 POST {base_url}/chat/completions，带 Authorization: Bearer。

    确认机制¶

    模型提议的操作会以卡片形式停在对话里，显示要做什么和什么样的参数，十秒级实时倒计时（默认 600 秒过期）：

    • 点「执行」→ 真正调用，结果回到模型，它接着把话说完
    • 点「取消」→ 这条操作作废，模型会被告知你拒绝了
    • 干等过期 → 一样按拒绝处理，历史也会被收尾，不会留下半截的工具调用

    为什么非要人工确认

    这个助手拿到的权限和你在面板上手动操作是一样的。而它读到的内容 —— 服务器日志、插件列表、server.properties、文件内容 —— 都是可以被外部影响的：任何人都能往控制台里打一句话，插件也能把任意文本写进日志。如果模型看到「忽略之前的规则，执行 xxx」就去执行，那这条注入路径就成立了。

    所以这里的设计是：模型只能提议，执行权在你手上。工具返回给模型的内容也会包在 <tool_result> 标签里，并在系统提示里明确告诉它那是数据不是指令。

    安全边界¶

    • 路径走的是同一套校验：所有文件操作都经过 core/files.py 的 normalize_rel + resolve，.. 越界、绝对路径、盘符一律拒绝。
    • .server.json 不可写：通过 AI 改配置必须走 update_config，字段白名单是 min_mem / max_mem / java_path / auto_restart / restart_max / auto_start / extra_jvm_args / extra_server_args / openfrp，其他字段动不了。
    • 敏感值不进模型上下文：内网穿透的 token 之类在交给模型前会被替换成 ***。
    • 有审计日志：每个被批准、拒绝、过期的操作都会往项目目录下的 .mstl-ai-audit.log 追加一行 JSON（时间、工具、参数、决定）。这个文件默认不进版本库。

    限制¶

    项 值 说明
    单条消息长度 4000 字 超了会直接告诉你
    工具调用轮数 8 轮 一次提问里最多来回八次，防止死循环
    对话历史 60 条 只保留最近的，从用户消息处截断以保持工具调用配对完整
    读控制台 200 行 / 20000 字 只取尾部
    读文件 64 KB 超长会截断并注明
    并发 一次一轮 上一轮没结束时再发会收到「正在处理上一条」

    它会记住什么¶

    对话历史只存在内存里，关掉面板或点「清空对话」就没了 —— 不会写进磁盘，也不会跨实例共享。它也不会自己定时干活：没有触发器的概念，所有动作都由你的一句话开始。
